# Naagmani Escape

A small beginner-made HTML5 Canvas arcade game using the images supplied for this project.

## Play locally
1. Extract `Naagmani_Escape.zip`.
2. Open `index.html` in a modern browser.
3. Click **START ESCAPE**.
4. Use Space, Up Arrow, W, or mouse click to flap. Press R after a crash to restart.

## Included
- Supplied haveli and temple backgrounds
- Supplied Shivangi image used as the flying character portrait
- Supplied cast photos randomly repeated as obstacle portraits
- Score, saved best score, collision/game-over, restart
- Background transition between the haveli and temple

## itch.io submission
Create a new itch.io project with project type **HTML**. Upload this ZIP and enable **This file will be played in the browser**. Keep `index.html` at the root of the ZIP. Set the viewport to 960 x 540.

## GitHub submission
Create a public repository, e.g. `naagmani-escape`, and upload `index.html` and `README.md`. Add the repository URL to the itch.io page.
